# Подключение онлайн-записи (Firebase) — пошагово

Сайт готов к онлайн-записи. Нужно один раз создать бесплатный проект Firebase
и вставить его данные. Займёт ~5–7 минут.

## 1. Создать проект
1. Откройте https://console.firebase.google.com → **Создать проект** (Add project).
2. Назовите, например, `atelier-neve`. Google Analytics можно выключить.

## 2. Добавить веб-приложение
1. На главной проекта нажмите иконку **</>** (Web).
2. Дайте имя (например `site`), **Register app**.
3. Появится блок `firebaseConfig = { apiKey: "...", ... }` — **скопируйте значения**.

## 3. Вставить данные в сайт
Откройте файл **`js/firebase-config.js`** и замените значения `"ВАШ_..."`
на скопированные (apiKey, authDomain, projectId, storageBucket,
messagingSenderId, appId). Больше ничего менять не нужно.

## 4. Включить базу данных
1. В консоли слева: **Build → Firestore Database → Create database**.
2. Выберите регион (ближе к вам, например `eur3`), режим — **Production**.
3. Перейдите на вкладку **Rules**, удалите всё и вставьте содержимое файла
   **`firestore.rules`** (лежит рядом с сайтом) → **Publish**.

## 5. Включить вход администратора и SMS
1. **Build → Authentication → Get started**.
2. Вкладка **Sign-in method** → включите **Email/Password** → Save.
3. Там же включите **Phone** (телефон) → Save — это SMS-подтверждение клиентов.
4. Вкладка **Users → Add user**:
   - Email: `admin@gmail.com`
   - Пароль: придумайте надёжный (запомните — это вход в кабинет).

> Если захотите другую почту администратора — поменяйте её в двух местах:
> в `js/firebase-config.js` (`adminEmail`) и в `firestore.rules` (строка с email),
> и заново опубликуйте правила.

## 6. Защита от накрутки расписания
Чтобы конкурент/бот не забил весь день фейковыми записями, включены 4 слоя.
Записать время **нельзя без подтверждения** — правила Firestore это гарантируют.

### 6.1. Капча (App Check + reCAPTCHA v3) — невидимо режет ботов
1. Зарегистрируйте сайт на https://www.google.com/recaptcha/admin
   (тип **reCAPTCHA v3**, добавьте домен сайта и `localhost` для теста).
   Скопируйте **Site key**.
2. Вставьте его в `js/firebase-config.js` → `APPCHECK_SITE_KEY`.
3. В консоли Firebase: **Build → App Check** → приложение Web → провайдер
   **reCAPTCHA v3** (вставьте там же секретный ключ reCAPTCHA).
4. Для Firestore сначала режим **Monitor** (следит, не блокирует). Убедитесь,
   что записи проходят, потом переключите на **Enforce**.

### 6.2. SMS-подтверждение номера — только при первой записи с устройства
Клиент при первой записи вводит код из SMS. Дальше с того же телефона/браузера
код больше не спрашивается.
- **Проверить бесплатно без карты:** Authentication → Sign-in method → Phone →
  **Phone numbers for testing** → добавьте выдуманный номер и код,
  например `+7 700 111 22 33` / `123456`. Реальные SMS не отправляются — вводите
  этот номер в форме и этот код.
- **Для реальных клиентов** нужен план **Blaze** (привязать карту): Firebase →
  **Upgrade → Blaze**. Первые **10 SMS в день бесплатно**, далее ~1–10 центов за SMS.
  При «1 запись в день» это копейки.

### 6.3. Лимит 1 запись в день на номер — уже встроен
Регулируется в `js/firebase-config.js` → `maxPerDay` (по умолчанию `1`).

### 6.4. Лимит по IP — обеспечивает сам Google
Phone Auth ограничивает ~150 запросов и 500 SMS с одного IP в час на стороне
Firebase. Отдельный сервер для этого не нужен.

## Готово!
- **Клиенты** записываются на самом сайте (кнопка «Записаться»): выбирают дату и
  свободное время (запись 2 часа, окно 9:00–19:00). При первой записи подтверждают
  номер по SMS. Двойная запись на одно время невозможна.
- **Вы** заходите в кабинет по адресу **`admin.html`** (откройте его в браузере
  или по ссылке на хостинге), входите под `admin@gmail.com` и видите
  недельный календарь. Клик по записи — можно **перенести** (дата/время/услуга)
  или **отменить**, двойной клик — перетащить мышью. Кнопка «+ Новая запись» —
  внести клиента вручную (без SMS).

## Публикация в интернете (по желанию)
Чтобы сайт и кабинет работали по ссылке, а не только локально, можно бесплатно
опубликовать на **Firebase Hosting**:
1. Установите Node.js, затем `npm install -g firebase-tools`.
2. В папке сайта: `firebase login`, затем `firebase init hosting`
   (public-папка — текущая, SPA — No), затем `firebase deploy`.
Либо залейте папку на любой статический хостинг (Netlify, Vercel, GitHub Pages).
